# MedicEdu Global Website

Static HTML/CSS/JS starter website for an MBBS-abroad education consultancy.

## Run
Open `index.html` directly, or use VS Code Live Server.

## Structure
- `index.html` — Home
- `about.html` — About Us
- `countries.html` — All destinations
- `admission.html` — Admission Process
- `contact.html` — Contact
- `countries/*.html` — 8 reusable country pages
- `css/style.css` — Design system
- `js/main.js` — Mobile menu, dropdown, slider, demo forms
- `img/` — Add your real images here
- `design.md` — Full design specification
- `agent.md` — Future update instructions

## Important
The contact forms are frontend demo forms and do not send real submissions yet.
Country-specific fees, eligibility, recognition and deadlines should be replaced with verified current data before launch.
